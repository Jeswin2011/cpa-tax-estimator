# CPA Tax Estimator

A desktop app for small businesses: upload bank statements, card statements and receipts, and every transaction is sorted into IRS categories with an estimate of the federal tax you owe.

**Website:** [jeswin2011.github.io/cpa-tax-estimator](https://jeswin2011.github.io/cpa-tax-estimator/)
**Downloads:** [latest release](https://github.com/Jeswin2011/cpa-tax-estimator/releases/latest)

## Install

```powershell
# Windows (PowerShell)
irm https://jeswin2011.github.io/cpa-tax-estimator/install.ps1 | iex
```

```bash
# Mac (Apple Silicon) and Linux
curl -fsSL https://jeswin2011.github.io/cpa-tax-estimator/install.sh | sh
```

The installers download the latest release, check its SHA-256 against GitHub's, and install it for your user account (no admin needed).

This repository holds the website and the release downloads only.

> Estimate only, not tax advice. Have a CPA review the numbers before you file.
